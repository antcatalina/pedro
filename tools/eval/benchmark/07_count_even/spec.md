# Count even numbers

Write a task that returns how many numbers in a list are even. Zero counts as even.

## Required signature

    task count_even(xs: list of whole) returns whole

## Details

- `count_even([1, 2, 3, 4, 5, 6])` is `3`.
- `count_even([1, 3, 5])` is `0`.
- `count_even([])` is `0`.
- `count_even([0])` is `1`.
